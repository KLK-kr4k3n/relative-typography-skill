# Relative Typography · 中英相对排版

把排版建模为“阅读基准 × 语义比例 × 字体光学校准”，再用内容宽度、行数和密度验证布局。适用于网页、界面、Figma frame、演示页、海报与展板；同一套决策模型可复用，各媒介仍须分别校准阅读基准。

Apple 提供语义样式、字重、行高、光学尺寸和动态布局的依据；本 skill 的跨媒介比例与阈值是**可调整的设计启发式**，不是 Apple 标准。需要出处或解释原理时读 [研究与证据](references/research.md)。

## 先确定坐标与角色

1. 识别媒介、目标观看距离/缩放、主要语言与地区、内容密度、阅读任务和既有 tokens。沿用合理的品牌字体及层级；只修复本任务涉及的缺口。
2. 分开记录页面宽 `W`、内容容器宽 `C`、标题容器宽 `Cₜ`。Figma 无限画布大小不是页面宽，编辑器缩放不是阅读基准。正文与标题可以占用不同的栏宽。
3. 以主要阅读正文为 `B = 1`。网页优先沿用用户根字号和现有正文基准；Figma 依据目标成品在预期阅读缩放下校准；印刷/展板依据实体尺寸、观看距离与可读样张校准。未知物理条件时，先给归一化关系并标明假设，不宣称已经验证远距离可读。
4. 给文字标记语义角色，再映射样式。标题、正文、操作标签、注释、图表文字按功能分配；英文翻译若与中文同等重要，应使用同一角色，不自动降成注释。HTML 标题级别由文档结构决定。

## 使用相对模型

```text
B = 当前阅读情境下、包含用户字号偏好的正文基准
Rᵢ = 语义角色的字号比例
Kᵢ,script = 该角色与字体组合的光学校准系数，初始为 1
Fᵢ,script = B × Rᵢ × Kᵢ,script
Hᵢ = Fᵢ × Lᵢ               # L 是相对该文字自身字号的行高
x = C / B，xₜ = Cₜ / B      # 相同单位；不是按页面像素猜测
```

`B` 不应因窗口变窄而自动变小。空间不足先换行、调栏、堆叠或分页。`W/B` 描述全页容量，`C/B` 才描述这段文字的局部容量；不以固定 `font-size/W` 代替阅读校准。

## 选取层级锚点

以下是起点，已有体系优先。只启用页面需要的角色，通常使用 4–6 种不同字号即可；不为凑层级而制造差异。

|角色|compact 操作密集|balanced 通用|editorial 阅读|display 展示|
|---|---:|---:|---:|---:|
|caption 注释|0.82|0.82|0.82|0.82|
|secondary 辅助说明|0.90|0.90|0.90|0.90|
|body / label 正文与标签|1.00|1.00|1.00|1.00|
|lead 导语|1.125|1.125|1.125|1.125|
|minor 小节标题|1.125|1.18|1.25|1.25|
|section 分区标题|1.29|1.41|1.65|2.00|
|title 页面主标题|1.42–1.65|1.65–2.00|2.00–2.50|2.40–3.20|
|display 首屏/海报标题|1.80–2.00|2.20–2.80|2.80–3.50|3.20–4.50|

compact 用于设置、工具栏、表单、表格；balanced 用于普通页面和卡片；editorial 用于长文、报告；display 用于短内容演示、封面、海报与展板。展板的近读区可用 editorial，远读区单独设 `B_far`；如要承载长文，不强行沿用展示区比例。

标题区间按局部容量取值，默认辅助算法为：

```text
t = clamp((xₜ − 20) / 40, 0, 1)
R_title = lo + (hi − lo) × t
```

20 与 60 是本包的初始调参点，按正文 em 表示容量，不是设备断点、可读性标准或强制规则。窄栏取区间低端；宽栏达到高端后停止放大。section 等其余角色不随容器连续增长。

已有实测标题总字宽 `A`（以目标标题字体、字重在 `B` 下的 em 计）及允许行数 `n` 时，`R_fit ≈ n × xₜ / A` 只做预估。词边界、字距与光学尺寸会改变换行，必须渲染复核。需要低于当前区间下限才能装入时，先增加行数、扩宽、调整构图；原文未经授权不要删改。不得水平压扁字体。

## 协同决定字重与中英文表现

- 正文以 Regular 为起点；标签可用 Medium；小标题与分区可用 Semibold；页面标题先试 Medium/Semibold，强调再用 Bold。数值 400/500/600/700 只是 CSS 起始映射，各字体的相同数值不保证同等视觉重量。
- 同字号可用字重、间距和位置区分角色。不要每上升一级就同时放大、加粗、加黑。注释重要时抬到正文角色；缩小和降低对比度不是唯一辅助层级手段。
- 同一语义先让中英文同字号、共基线渲染，再比较汉字字面、拉丁 x-height/cap-height、数字与笔画密度。只有出现实测失衡时再设置 `K` 或字体专属字重。可先在 0.95–1.05 内试调；这不是通用中文/英文换算率，也不是硬限制。避免逐词、逐字符串随意修正。
- 分开的双语段落可以有不同的光学校准与行高；一句混排优先保持字号和基线，使用匹配的字体对。区分 SC/TC/HK 等地区字形。用真实内容检查数字、标点、全大写、重笔画汉字和 fallback。
- 中文默认不加字距；不把 SF 的 tracking 表套给汉字或其他字体。英文也先使用字体默认 kerning。只有实际字体支持时启用 optical sizing，不固定套用旧版 Text/Display 切换阈值。

具体混排、字重标定、行高、栏宽与留白见 [版式规则](references/layout-rules.md)。

## 把文字映射到页面

- 短标签起始行高约 `1.25–1.45 × F`；英文阅读正文 `1.45–1.65 × F`；中文/混排正文 `1.55–1.80 × F`；中文多行大标题 `1.15–1.30 × F`。按字体升降部和实际换行调整，不把 UI 紧行高复制给长文。
- 栏宽先估算再实测：中文近似每字 `1em`，英文应测目标样本的平均 advance；`ch` 是数字 0 的宽度，不是平均字符宽。中文长文可先试每行 24–40 字，英文 45–75 字符，均为本包启发式。不要把这些范围套给按钮或短标题。
- 用正文 `B` 管页面与组件留白，用文字自己的 `em` 管段内间距。可先试标签间隙 `0.25–0.5B`、组件内边距 `0.75–1.25B`、模块间隙 `1.5–3B`。标题到其内容的距离应小于到前一区块的距离；固定设计系统优先。
- 网页优先用 `rem`/相对 tokens；用户放大时允许重排和增高。Figma 中记录 `B` 及比例，落成 text styles/variables，再用 Auto Layout 或相应约束验证。印刷/展板换算为 mm 或 pt 后按实物尺寸打样。不要把 CSS px、Figma 坐标和印刷 pt 当成天然等价单位。
- 无限画布、看板与展板可以分阅读区；每区明确 `B` 与阅读距离。默认只有一个正文基准，增加独立基准必须有阅读任务依据，不能为每张卡片自行缩放。

媒介落地、CSS 示例和计算样例见 [映射示例](references/adapters-and-examples.md)。需要确定性比例计算时运行 `scripts/type_scale.py`；只用 Python 标准库，输出 JSON，不调用设计工具。

## 验证并交付

先在目标媒介渲染真实中英文内容。至少检查最窄容器、常用宽度、宽画布、长标题、fallback 字体和放大状态；原地修复溢出、断行、字重失衡与层级竞争。不能执行渲染时，明确仅完成 token/文档验证。

网页按目标可访问性要求检查文本 200% 放大、适用内容在等效 320 CSS px 下重排，以及用户覆盖行高/字距后信息仍完整。这些是相应 WCAG 条款中的验证条件，不是要求所有设计默认采用这些数值；二维画布等例外要按内容判定。完整符合性不能仅靠本 skill 保证。

交付：阅读情境与 `B` 的依据；角色 → 比例 → 字重 → 行高 → 容器映射表；中英校准；响应式/缩放策略；已完成的验证与未验证假设。实际实现可输出绝对计算值，但必须保留可追溯的比例与基准。
